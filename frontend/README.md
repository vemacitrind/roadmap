# Frontend - Roadmap Project

This is the frontend part of the Roadmap platform, built with modern and efficient technologies to deliver a smooth user experience.

---

## Technology Stack

- **Vite**: Fast build tool and development server for modern web projects.  
- **React**: Powerful UI library for building interactive user interfaces.  
- **Shadcn UI**: Tailwind CSS based component library for beautiful and accessible UI elements.  
- **Firebase**: Backend as a service for authentication, database, and real-time updates.

---

## Features

- Responsive and clean UI using Shadcn components.  
- Fast and optimized build and hot-reload with Vite.  
- User authentication and data management powered by Firebase.  
- Integration with backend APIs for roadmap data and community features.  
- Smooth navigation and progress tracking UI.
